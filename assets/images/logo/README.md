# AVASTRA SpaceShare — Official Logo Assets

This directory contains the official brand assets for the **AVASTRA SpaceShare** project. All contributors should use these standardized logo assets across web pages, documentation, and UI components.

---

## 🎨 Asset Index & Guidelines

| File Name | Format | Description | Recommended Usage |
| :--- | :--- | :--- | :--- |
| [`colored-logo.svg`](./colored-logo.svg) | SVG | Full color logo (Icon + Text) | Website Header (Light Theme), Main Branding |
| [`colored-logo.png`](./colored-logo.png) | PNG | High-res full color raster logo | Cards, Previews, External Embeds |
| [`transparent-logo.svg`](./transparent-logo.svg) | SVG | Logo with transparent background | Headers, Footers, Dynamic Dark/Light backgrounds |
| [`transparent-logo.png`](./transparent-logo.png) | PNG | High-res transparent raster logo | Modals, Banners, Social Share Cards |
| [`only logo.svg`](./only%20logo.svg) | SVG | Icon mark only (3D Cube) | Favicon, Mobile Navbar Icon, Compact UI |
| [`oly logo in large size.svg`](./oly%20logo%20in%20large%20size.svg) | SVG | Large scale icon mark | Hero Sections, Splash Screens, App Badges |
| [`colored-logo.pdf`](./colored-logo.pdf) | PDF | Vector PDF | Reports, PDF Invoices, Print Media |
| [`transparent-logo.pdf`](./transparent-logo.pdf) | PDF | Vector PDF (Transparent) | Print Documentation, Branding Documents |
